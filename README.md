## About

### 🐧 Linux / macOS
To run the app, create a Python virtual environment and install the dependencies:
```bash
python3 -m venv env
source env/bin/activate
pip3 install -r requirements.txt
```
then launch the app using
```bash
python3 app.py
```

### 🪟 Windows
To run the app, create a Python virtual environment and install the dependencies:
```bash
python -m venv env
env\Scripts\activate
pip install -r requirements.txt
```
then launch the app by
```bash
python3 app.py
```

Once started, the website will be accessible in your browser at: [http://127.0.0.1:1234]
